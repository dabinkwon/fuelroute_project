## 9. 단계별 커밋과 README 진행 기록 — 2026-11-18

- 사용자 요청으로 기존 완료 작업의 최종 파일을 기획·환경 구성·프론트·API 연동·경로 검증 단계의 로컬 커밋으로 나눴다.
- 각 코드 단계의 Git 트리를 별도 폴더로 추출해 검증했다. 기반 서버·설정·안전거리 점검과 저장 테스트 1개, API 단계 테스트 45개, 경로 검증 단계 테스트 84개가 통과했다.
- README에 단계별 완료 내용·검증 결과·커밋 ID를 추가하고 별도의 문서 커밋으로 기록한다. [진행표](../README.md#단계별-진행-기록)를 따른다.
- 실제 API 재호출·재배포·원격 푸시는 수행하지 않았다. 인증키·가상환경·로컬 원본 응답과 Git 스냅샷 검증 폴더는 Git에서 제외했다.
- 개인 TASKS/daily와 개발 TASK의 완료 상태는 변경하지 않았다.

## 10. 실행 명령을 Bash 기준으로 통일 — 2026-11-18

- 사용자 요청에 따라 README와 프론트 문서의 터미널 예시를 Bash 문법으로 바꿨다.
- 현재 Windows에서는 Git Bash의 `source .venv/Scripts/activate`로 가상환경을 활성화하고 이후 `python -m ...` 명령을 사용한다. Linux/macOS 활성화 경로도 별도로 안내했다.
- 환경 파일 복사는 기존 `.env`를 보존하는 Bash 조건문으로, Netlify 경로는 상대경로로 정리했다.
- AGENTS에 앞으로의 안내·문서 명령도 Bash 기준으로 작성하도록 반영했다. 개인 TASKS/daily와 애플리케이션 코드는 변경하지 않았다.
- Git Bash에서 가상환경 활성화와 doctor 실행을 확인했고, 문서의 Bash 예시 9개를 `bash -n`으로 검증했다. 외부 API 호출·재배포는 수행하지 않았다.
