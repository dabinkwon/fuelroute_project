# 외부 API 호출 한도와 공개 이용조건

2026-11-18 계정 확인값과 2026-11-19 Kakao Local 추가 검증을 기록한다. 공개 문서 조사와 사용자 제공 계정 정보를 구분한다. 이 기록은 개별 계약이나 상용 서비스에 대한 승인 자체를 뜻하지 않는다.

| API | 현재 계정 한도·기간 | 확인 근거 |
|---|---|---|

| Kakao Mobility 자동차 길찾기 | 10,000회/일 | 사용자 확인값 및 [공개 쿼터 안내](https://developers.kakao.com/docs/ko/getting-started/quota) |

## Opinet

- 일반 API는 무료 조회 범위로 안내되며, 더 높은 일반 API 호출량은 제휴 절차가 별도로 안내되어 있다. 현재 계정에는 기본 300회/일을 적용한다.
- 공식 페이지의 저작권정책은 자료 이용 시 권리와 출처를 확인하도록 하며 수익을 얻는 이용에는 사전 협의·허락을 안내한다. 일반 키 발급을 무제한 재배포나 상업 이용 허가로 해석하지 않는다.
- 개발에서는 명시적 검색점과 후보 수를 제한하고 필요한 후보만 상세 조회한다. 원본 가격·기준시각을 보존하며 제공하지 않은 실시간 가격을 생성하지 않는다.

근거: [API 안내 및 페이지 내 저작권정책](https://www.opinet.co.kr/user/custapi/custApiInfo.do).

## Kakao Mobility 자동차 길찾기

- 앱에 적용된 자동차 길찾기 한도를 사용한다. 다중 출발지·목적지 등 다른 API에 같은 한도를 적용하지 않는다.
- 운영정책의 쿼터 및 제한 항목은 API별 요청수를 별도 가이드에 따르도록 한다. 현재 앱의 유료 API 설정·추가 계약·초과 과금 승인을 추정하지 않는다.
- 서비스 약관에는 취득 정보의 복제·제공 등에 관한 제한이 있다. API 응답을 독립 데이터 상품이나 공개 원본 데이터베이스로 재배포할 권한을 얻었다고 해석하지 않는다.
- 개발에서는 동일 옵션의 기본·접근·경유 요청을 제한된 횟수로 실행한다. 일시적 경로 계산에는 원본 좌표를 사용하고, 개발 기록에는 필요한 거리·시간·요약만 남긴다.

근거: [쿼터](https://developers.kakao.com/docs/ko/getting-started/quota), [운영정책 제6조](https://developers.kakao.com/terms/ko/site-policies), [서비스 약관](https://developers.kakao.com/terms/ko/site-terms), [자동차 길찾기 명세](https://developers.kakaomobility.com/guide/navi-api/directions.html).

## Kakao Local 주소·장소 검색 — 입력 위치 해석

- 주소 검색 `https://dapi.kakao.com/v2/local/search/address.json`을 먼저 호출하고 0건일 때만 `https://dapi.kakao.com/v2/local/search/keyword.json`을 호출한다. 기존 `KAKAO_REST_API_KEY`를 사용하며 해당 앱의 카카오맵 활성화가 필요하다.
- 현재 앱은 초기 403/비활성 응답 후 사용자가 활성화했다고 확인했고, 대구·서울 검색의 정상 응답을 확인했다. 자동차 길찾기 10,000회/일을 Local 한도로 옮겨 적지 않는다. 실제 앱 무료 쿼터 적용과 주소/장소 검색 한도 수치는 콘솔 확인 전이다.
- 코드 상한은 위치당 최대 2회, 요청당 출발/목적 최대 4회다. 첫 페이지 5건만 요청하며 전체 결과가 여러 개면 자동 선택하지 않는다. 동일 실행의 동일 지명은 재사용하고 실패한 요청을 자동 재시도하지 않는다. HTTP 400의 제공사 code=-10도 호출 한도 오류로 분류한다.
- `analyze`는 GMS 1회와 필요할 때 위 위치 검색만 수행한다. `recommend`·`route-spike`의 기존 호출 예산과 별도이며, 현재 자동으로 길찾기·주유소 조회를 이어서 실행하지 않는다.

근거: [주소/장소 API](https://developers.kakao.com/docs/ko/local/dev-guide), [카카오맵 활성화·이용 정책](https://developers.kakao.com/docs/ko/kakaomap/common), [실제 검증](verification/2026-11-19-geocoding.json).

## 전국휴게소정보표준데이터

- 데이터 상세는 무료 제공과 이용허락범위 안내 링크를 제공한다. 포털 정책은 제3자 권리와 개별 데이터에 부착된 이용허락 조건을 확인하도록 안내한다.
- 이번에 확인한 공개 응답만으로 특정 공공누리 유형이나 무제한 상업 이용 허가를 확정하지 않는다. 공개 서비스의 재배포 범위를 확대할 때 상세의 이용허락 표시를 다시 확인한다.
- 개발에서는 제공기관·데이터 기준일을 보존하고, 같은 휴게소·주유소 또는 실시간 시설 상태라는 확인되지 않은 사실을 추가하지 않는다. 현재 개발계정의 일일 한도와 활용기간을 따른다.

근거: [데이터 상세](https://www.data.go.kr/data/15025446/standard.do), [포털 이용허락범위 및 이용약관](https://www.data.go.kr/ugs/selectPortalPolicyView.do).

## 현재 코드에 적용한 호출 범위

`route-spike` 기본값은 검색점 최대 3개와 평가 후보 최대 3개다.

| 제공사 | 한 번의 실험에서 최대 호출 수 | 구성 |
|---|---:|---|
| Opinet | 6회 | 후보 검색 3회 + 상세 조회 3회 |
| Kakao | 7회 | 기본 1회 + 접근 3회 + 경유 3회 |
| GMS | 0회 | 명시적 조건과 일반 Python 계산만 사용 |

설정된 `max_candidates`가 N이면 Opinet 상한은 검색점 수+N, Kakao 상한은 1+2N이다. 인증·설정·한도 오류는 즉시 중단하며 자동 재시도하지 않는다. 실제 호출 수는 결과의 `api_call_counts`와 개별 호출 메타에 기록한다.

`recommend`는 재계획 최대 2회·회차당 최대 3곳·전체 최대 9곳 평가가 기본값이다. 미평가 후보를 먼저 재사용하고, 없을 때만 회차당 검색점 한 곳을 추가한다.

| 제공사 | 기본 추천 한 번의 최대 호출 수 | 구성 |
|---|---:|---|
| Opinet | 14회 | 최초 검색 3회 + 추가 검색 최대 2회 + 상세 최대 9회 |
| Kakao | 19회 | 기본 1회 + 접근/경유 최대 18회 |
| GMS | 0회 | 명시적 조건과 일반 Python 계산만 사용 |

검색/평가 설정을 늘리면 예산도 증가한다. 전체 평가 수를 E, 최초 검색점 수를 P, 재계획 상한을 R이라 하면 Opinet은 최대 P+R+E, Kakao는 최대 1+2E다. 캐시·조기 제외·추천 발견으로 실제 호출은 줄어들 수 있다. 동일 실행의 경로·상세·검색 캐시는 호출 종료 시 폐기한다. 이번 추천 실호출에서는 Opinet 6회·Kakao 7회를 사용했고 최초 회차에서 종료했다. [추천 검증 기록](verification/2026-11-18-recommendation.json)

이 상한은 실행 한 번의 요청 예산이다. 여러 프로세스·사용자의 공유 일일 한도 집계는 아직 구현하지 않았다. 전체 경로를 빠짐없이 검색하거나 모든 후보의 최저가를 보장하는 단계도 아니다.
